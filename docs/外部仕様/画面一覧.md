# 画面一覧

最終実装確認日: 2026-08-30

## 共通レイアウト

- 通常画面には、サービスTOPへ戻る `GatherQuiz` ヘッダーと、利用規約・プライバシーポリシー・お問い合わせへのフッターを表示する。
- URLに `/board` または `/quizzes/` を含む画面では、投影・入力領域を広く取るためヘッダーとフッターを表示しない。
- `/` は `/gather` へリダイレクトする。定義されていないURLはエラーページを表示する。

## 画面

| 画面 | URL | 主な役割 | 仕様 |
| :--- | :--- | :--- | :--- |
| サービスTOP | `/gather` | 大会作成と最近見た大会への入口 | [詳細](画面仕様/サービスTOP.md) |
| 大会作成 | `/gather/tournaments/new` | 大会設定の新規登録 | [詳細](画面仕様/大会作成.md) |
| 大会編集 | `/gather/tournaments/:tournamentId/edit` | 既存の大会設定を更新 | [詳細](画面仕様/大会作成.md) |
| 大会作成完了 | `/gather/tournaments/:id/created` | 招待URLと管理用パスワードを案内 | [詳細](画面仕様/大会作成完了.md) |
| 大会ポータル | `/gather/tournaments/:id` | 主催者ログイン、参加者登録・ログインの入口 | [詳細](画面仕様/大会ポータル.md) |
| 参加者登録 | `/gather/tournaments/:id/register` | 参加者名の登録とパスワード発行 | [詳細](画面仕様/参加者登録.md) |
| 主催者用管理 | `/gather/tournaments/:tournamentId/admin` | 作成状況確認、大会編集・開始 | [詳細](画面仕様/主催者_管理.md) |
| 参加者ダッシュボード | `/gather/tournaments/:tournamentId/participants/:participantId` | 問題の作成状況確認・作成・編集 | [詳細](画面仕様/参加者ダッシュボード.md) |
| 問題作成・編集 | `/gather/tournaments/:tournamentId/participants/:participantId/quizzes/new` | 問題と解答の登録・更新 | [詳細](画面仕様/問題作成_編集.md) |
| 問題選択ボード | `/gather/tournaments/:tournamentId/board` | 大会進行、問題選択、終了操作 | [詳細](画面仕様/問題選択ボード.md) |
| 問題表示 | `/gather/quizzes/:quizId` | 問題を投影し、既読に更新 | [詳細](画面仕様/問題表示.md) |
| 解答表示 | `/gather/quizzes/:quizId/answer` | 解答を投影し、ボードへ戻る | [詳細](画面仕様/解答表示.md) |
| 大会終了ダイアログ | 問題選択ボード内 | 全出題終了を案内してポータルへ戻す | [詳細](画面仕様/大会終了.md) |
| 利用規約 | `/terms` | 現行の利用規約文を表示 | [詳細](画面仕様/利用規約.md) |
| プライバシーポリシー | `/privacy` | 現行の個人情報保護方針を表示 | [詳細](画面仕様/プライバシーポリシー.md) |
| お問い合わせ | `/contact` | 問い合わせ先メールアドレスを表示 | [詳細](画面仕様/お問い合わせ.md) |
| エラー | その他 | 存在しない画面からTOPへ誘導 | [詳細](画面仕様/エラー.md) |

## 補助ダイアログ

- 主催者ログイン、参加者ログイン: 大会ポータル内
- 問題・解答プレビュー、レギュレーション確認: 参加者ダッシュボード内
- レギュレーション確認: 問題作成・編集、問題選択ボード内
- 大会終了: 問題選択ボード内

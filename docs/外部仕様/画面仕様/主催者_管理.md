# 主催者用管理ページ

## 基本情報

- URL: `/gather/tournaments/:tournamentId/admin`
- 目的: 大会情報と参加者の問題作成状況を確認し、大会の編集・開始・進行を行う。
- レイアウト: 共通ヘッダー・フッターあり。

## 表示内容

- 大会名
- ステータスが `in_progress` または `finished` の場合は「開始済み」バッジ
- 招待URL
- 参加者名と `作成済み問題数 / 必要問題数` の一覧
- 未開始時は「この内容で大会を開始する」、開始済み時は「問題ボードへ移動する」
- 「大会概要を編集する」「大会ポータルへ戻る」

## 操作

| 操作 | 結果 |
| :--- | :--- |
| 大会概要を編集する | 大会編集ページへ遷移する。 |
| この内容で大会を開始する | 直前に入力した参加チーム数・チーム名をステータス `in_progress` と同時に保存し、問題選択ボードへ遷移する。チーム設定は大会作成・概要編集では行わない。 |
| 問題ボードへ移動する | 問題選択ボードへ遷移する。 |
| 大会ポータルへ戻る | 対象大会のポータルへ遷移する。 |

読み込み中はスピナー、ステータス取得失敗時はインラインでエラーメッセージを表示する。大会開始失敗時は入力を保持し、インラインでエラーを表示する。開始中は二重送信を防ぎ、開始後はチーム設定欄を表示しない。

## 現行実装上の制約

- 表示する招待URLは `${origin}/tournaments/:id` で組み立てられ、実際の画面URLに必要な `/gather` が欠けている。
- 招待URLのコピーボタンはない。
- 「一度開始すると、問題の編集や参加者の追加はできない」と案内するが、開始後も編集リンクを表示し、APIにも追加・編集を拒否する制御がない。
- 主催者ログイン済みかを検証するアクセス制御はない。

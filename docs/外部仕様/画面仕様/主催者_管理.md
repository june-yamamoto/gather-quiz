## 5. 主催者用 管理ページ

### 画面の目的
- 主催者が参加者の問題作成状況を把握し、大会の概要編集や開始操作を行えるようにする。

### 画面レイアウト

```
+----------------------------------------------------------------------+
| ヘッダー                                                             |
|   GatherQuiz                                                         |
+----------------------------------------------------------------------+
| メインコンテンツ                                                       |
|   ## 管理ページ：「〇〇〇〇（大会名）」 [開始済みバッジ]              |
|                                                                      |
|   招待URL： https://gather.quiz/tournaments/a1b2...  [コピー]         |
|   +--------------------------+                                       |
|   | [ 大会概要を編集する ]   |                                       |
|   +--------------------------+                                       |
|                                                                      |
|   --- 参加者の問題作成状況 ---                                         |
|   +----------------------------------------------------------------+ |
|   | 参加者ID         | 作成状況                                  | |
|   |------------------|-------------------------------------------| |
|   | Tanaka           | 完了 (5/5 問)                             | |
|   | Sato             | 作成中 (3/5 問)                           | |
|   +----------------------------------------------------------------+ |
|   ---                                                                |
|                                                                      |
|   +----------------------------------+                               |
|   |   [ この内容で大会を開始する ]   |                               |
|   +----------------------------------+                               |
|   (または [ ボードへ移動する ])                                      |
|                                                                      |
|   <一度開始すると編集はできません>                                     |
+----------------------------------------------------------------------+
```

### 各要素の説明
- **開始済みバッジ**: 大会ステータスが `in_progress` または `finished` の場合に表示されます。
- **大会開始ボタン**: 未開始の場合に表示。クリックすると大会を開始します。
- **ボードへ移動ボタン**: 開始済みの場合に表示。クリックするとクイズボードへ移動します。

### 要素と動作の定義
| 要素名 | 種別 | 動作・仕様 |
| :--- | :--- | :--- |
| **この内容で大会を開始する** | **ボタン** | ・クリックすると「本当に開始しますか？」確認。<br>・OKでステータスを更新し、「問題選択ボードページ」へ遷移。 |
| **ボードへ移動する** | **ボタン** | ・大会が既に開始されている場合に表示。<br>・「問題選択ボードページ」へ遷移する。 |

### 設計のポイント
- **状態の可視化**: 現在大会がどのような状態にあるか（準備中、開催中）を一目で分かるようにする。

# 参加者登録ページ

## 基本情報

- URL: `/gather/tournaments/:id/register`
- 目的: 大会へ参加者名を登録し、再ログイン用パスワードを発行する。
- レイアウト: 共通ヘッダー・フッターあり。

## 登録前

- 「あなたの名前」必須入力と「この名前で参加する」ボタンを表示する。
- 空白だけの名前、または大会IDがない場合は「名前を入力してください。」とアラート表示する。
- 同じ大会で使用済みの名前はAPIの409応答を受け、「その名前は既に使用されています。別の名前を入力してください。」と表示する。
- その他の登録失敗は「エラーが発生しました。」と表示する。

## 登録完了後

- 同じ画面内で「登録完了！」へ表示を切り替える。
- APIが自動生成した参加者パスワードを大きく表示し、再ログイン用に控えるよう案内する。
- 「ダッシュボードへ移動する」で、発行された参加者IDのダッシュボードへ遷移する。

## 現行実装上の制約

- パスワードのコピー機能や再表示・再発行機能はない。
- 大会が開始済みかどうかによる新規登録の制限はない。
- 登録成功後に認証セッションは作成しない。

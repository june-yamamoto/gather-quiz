# 大会ポータルページ

## 基本情報

- URL: `/gather/tournaments/:id`
- 目的: 大会名を示し、主催者と参加者をそれぞれの操作へ誘導する。
- レイアウト: 共通ヘッダー・フッターあり。

## 表示内容

- 大会取得前は「大会ポータル」、取得後は `大会: {大会名}` を表示する。
- ログイン・登録の前に「大会概要」を表示する。現在の参加人数、1人あたりの作成問題数、大会の状態（準備中・開催中・終了）を確認できる。
- 「作成する問題の概要」には問題順にラベル、配点、出題形式を表示する。ラベル未設定は「概要は未設定」、旧大会の形式未指定は「参加者が出題形式を選択」とする。
- ジャンルとレギュレーションを表示し、レギュレーションの改行を保持する。未設定の場合はその旨を明示する。
- 人数は大会ステータスAPIから取得した参加者数（登録がなければ0人）。取得中は「確認中…」、失敗時は「取得できませんでした」とし、0人と区別する。投稿済みの問題・解答や参加者名は概要に表示しない。
- 主催者カードに「主催者としてログイン」を表示する。
- 参加者カードに「参加者として新規登録」「参加者としてログイン」を表示する。
- 大会取得成功時、サービスTOPの「最近アクセスした大会」用履歴を最大5件で保存する。

## 主催者ログイン

- ダイアログで管理用パスワードを入力する。Enterキーまたは「ログイン」で送信する。
- 成功すると主催者用管理画面へ遷移する。
- 失敗すると「パスワードが違います。」とアラート表示し、入力を空にする。

## 参加者操作

- 「参加者として新規登録」は参加者登録ページへ遷移する。
- 参加者ログインダイアログでは名前とパスワードを入力する。
- ログイン成功時は返却された参加者IDを使って参加者ダッシュボードへ遷移する。
- 失敗すると「名前またはパスワードが違います。」とアラート表示する。

## 現行実装上の制約

- ログイン成功後のトークン、セッション、画面アクセス制御は実装されていない。
- 大会取得失敗時、このページ自身には専用のエラー表示やエラーページへの遷移処理がない。

参加者ログインはIDとパスワードを入力する。旧登録者には従来の名前をID欄へ入力する案内を表示する。5回の失敗で15分間の試行制限（429）を案内する。

## 4. 大会ポータルページ

### 画面の目的
- 招待URLでアクセスしたユーザー（主催者・参加者）を、それぞれの役割に応じた正しいページへ誘導する。

### 画面レイアウト

```
+----------------------------------------------------------------------+
| ヘッダー                                                             |
|   GatherQuiz                                                         |
+----------------------------------------------------------------------+
| メインコンテンツ                                                       |
|   ## 大会: 「〇〇〇〇（大会名）」                                     |
|   参加方法を選択してください                                           |
|   ---                                                                |
|   +-----------------------------+ +--------------------------------+ |
|   |   ## 主催者の方             | |   ## 参加者の方               | |
|   |   大会の管理や進行は        | |   問題の作成や確認は          | |
|   |   こちらから                | |   こちらから                  | |
|   |                             | |                                | |
|   |   +-----------------------+ | |   +------------------------+ | |
|   |   | [主催者としてログイン]| | |   |[参加者として新規登録]  | | |
|   |   +-----------------------+ | |   +------------------------+ | |
|   |                             | |   +------------------------+ | |
|   |                             | |   |[参加者としてログイン]  | | |
|   |                             | |   +------------------------+ | |
|   +-----------------------------+ +--------------------------------+ |
+----------------------------------------------------------------------+

[ログインダイアログ（主催者・参加者共通デザイン）]
+------------------------------------------+
| 〇〇ログイン                             |
| ---------------------------------------- |
| パスワード（参加者の場合は名前も）:      |
| [ _____________________ ]                |
|                                          |
| [キャンセル]   [ログイン]                |
+------------------------------------------+
```

### 各要素の説明
- **大会名**: ユーザーが目的の大会ページに正しくアクセスできたことを確認させます。
- **主催者エリア**:
  - `[主催者としてログイン]`: クリックするとパスワード入力ダイアログが開きます。
- **参加者エリア**:
  - `[参加者として新規登録]`: まだ登録していないユーザー向け。登録ページへ遷移します。
  - `[参加者としてログイン]`: 登録済みのユーザー向け。クリックすると名前とパスワード入力ダイアログが開きます。

### 要素と動作の定義
| 要素名 | 種別 | 動作・仕様 |
| :--- | :--- | :--- |
| **主催者としてログイン** | **ボタン** | ダイアログを開き、管理用パスワードの入力を求める。成功すると「主催者用 管理ページ」へ遷移。 |
| **参加者として新規登録** | **ボタン** | 「参加者登録ページ」へ遷移する。 |
| **参加者としてログイン** | **ボタン** | ダイアログを開き、名前とパスワードの入力を求める。成功すると「参加者ダッシュボードページ」へ遷移。 |

### 設計のポイント
- **入口の分離**: 主催者と参加者の動線を明確に分けつつ、リピーター（ログイン）と新規（登録）の動線も確保する。

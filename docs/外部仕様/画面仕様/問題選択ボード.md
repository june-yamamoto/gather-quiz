## 7. 問題選択ボードページ

### 画面の目的
- 全員が作成した問題を一覧表示し、どの問題に挑戦するかを選択できるようにする。

### 画面レイアウト

```
+----------------------------------------------------------------------+
|                                                 [ルール確認]         |
| +--------------------+                                               |
| | (大会のキービジュアル) |  ## 〇〇〇〇クイズ大会（大会名）             |
| +--------------------+                                               |
|                                                                      |
|        <Tanakaさん>      <Satoさん>       <   ???    >                |
|      +-------------+   +-------------+   +-------------+             |
| 10点 |  [  歴史  ]   | |  [  10点  ]   | |  [  10点  ]   |             |
|      |  [  10点  ]   | |               | |               |             |
|      +-------------+   +-------------+   +-------------+             |
| 20点 |  [  20点  ]   | | (  20点  )済 | |  [  20点  ]   |             |
|      +-------------+   +-------------+   +-------------+             |
| 30点 |  (  30点  )済 | |  [  30点  ]   | | (未作成)      |             |
|      +-------------+   +-------------+   +-------------+             |
|                                                                      |
|               (全問終了時に表示)                                      |
|          +--------------------------+                                |
|          |    大会を終了する！       |                                |
|          +--------------------------+                                |
+----------------------------------------------------------------------+
```

### 各要素の説明
- **ルール確認ボタン**: クリックすると大会のレギュレーションを表示するダイアログが開きます。
- **未作成の問題**: 点線枠で「未作成」と表示され、クリックできません。
- **大会終了ボタン**:
  - 参加者全員の作成済み問題が全て「既読（出題済み）」になった場合に表示されます。
  - クリックすると「お疲れ様でした！」ダイアログが表示され、そこから大会ポータルへ戻ることができます。

### 要素と動作の定義
| 要素名 | 種別 | 動作・仕様 |
| :--- | :--- | :--- |
| **問題カード** | **ボタン** | ・未出題・出題済みに関わらずクリック可能。<br>・未作成の場合はクリック不可。<br>・クリックすると、その問題に対応する「問題表示ページ」に遷移し、問題の状態を「既読」に更新する。<br>・ジャンルが設定されている場合、カード内にジャンル名が表示される |
| **大会を終了する** | **ボタン** | 全問既読時に出現。クリックで終了ダイアログを表示。 |

### 設計のポイント
- **進行状況の明確化**: 全ての問題が終わったことを明確に伝え、スムーズにイベントを締めくくる導線を提供する。

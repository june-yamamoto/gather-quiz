# 問題選択ボードページ

## 基本情報

- URL: `/gather/tournaments/:tournamentId/board`
- 目的: 参加者ごとの問題枠と出題状況を表示し、大会を進行する。
- レイアウト: ヘッダー・フッターなし。横幅制限のない投影向け表示。

## 表示内容

- 大会名と「ルール確認」ボタン
- 参加者ごとの列と、大会の配点設定に対応する問題カード
- 作成済みカードには配点と任意のジャンルを表示する。
- 未作成枠は点線表示の「未作成」とし、選択できない。
- 既読カードはグレー表示するが、再選択できる。
- 各参加者の名前は、その参加者の問題が1問も既読でない間は `???` と表示し、1問以上既読になると表示する。

## 操作

| 操作 | 結果 |
| :--- | :--- |
| ルール確認 | レギュレーションをダイアログ表示する。未設定時はその旨を表示する。 |
| 作成済み問題カード | 問題表示ページへ遷移する。既読カードも選択可能。 |
| 大会を終了する！ | 大会終了ダイアログを開く。 |

## 終了条件

- 作成済み問題が1問以上あり、その全てが既読の場合にだけ「大会を終了する！」を表示する。
- 未作成枠は終了条件に含めない。
- 終了操作の詳細は [大会終了ダイアログ](大会終了.md) を参照する。

読み込み中はスピナー、取得失敗時はインラインでエラーメッセージを表示する。

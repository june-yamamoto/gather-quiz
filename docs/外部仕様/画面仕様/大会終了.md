# 大会終了ダイアログ

## 基本情報

- 表示場所: 問題選択ボード内
- 表示条件: 作成済み問題が1問以上あり、その全てが既読になった後に「大会を終了する！」を押す。
- 目的: 全問題の終了を案内し、大会ポータルへ戻す。

## 表示内容

- 「お疲れ様でした！」
- 「全ての問題が終了しました。」
- 「クイズ大会にご参加いただきありがとうございました。」
- 「大会ポータルへ戻る」ボタン

ダイアログ外を閉じる操作では問題選択ボードに留まる。「大会ポータルへ戻る」で対象大会のポータルへ遷移する。

## 現行実装上の制約

- 独立した大会終了ページは存在しない。
- 大会ステータスを `finished` へ更新するAPI呼び出しは行わない。そのため管理画面上のステータスは `in_progress` のままになる。
- 大会キービジュアルはデータモデル・画面ともに実装されていない。

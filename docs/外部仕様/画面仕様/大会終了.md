# 大会終了と結果発表

作成済み問題が1問以上あり、全てが既読の場合にボードの「大会を終了する！」から確認ダイアログを開く。

「大会を終了して順位を発表」で大会を `finished` に更新する。チーム採点が有効な場合は、全問題で解答を開き全チームの判定を保存している必要がある。未保存の場合はエラーを表示し、ボードに戻って修正できる。

終了後は `/gather/tournaments/:tournamentId/results` へ遷移し、下位から順に結果を発表する。大会ポータルへ戻るリンクと演出を省略するボタンがある。終了済みのボードからも結果ページを開ける。

詳細は [チーム採点](../チーム採点.md) を参照。

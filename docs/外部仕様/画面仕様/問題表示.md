## 8. 問題表示ページ

### 画面の目的
- 選択された一つの問題（問題文、画像、リンク）を、参加者全員に見やすく表示する。

### 画面レイアウト

```
+----------------------------------------------------------------------+
|  [歴史] (左上にバッジ表示)             50点問題 (右上にバッジ表示)    |
|                                                                      |
|      Q. ここに問題文が大きな文字で表示されます。                     |
|                                                                      |
|               +----------------------------------+                   |
|               |   (ここに添付画像が大きく表示)   |                   |
|               +----------------------------------+                   |
|                                                                      |
|      参考リンク： https://example.com/hint                           |
|                                                                      |
|                   +----------------------------------+               |
|                   |         [ 正解を見る ]         |               |
|                   +----------------------------------+               |
+----------------------------------------------------------------------+
```

### デザインの特徴
- **装飾**: 画面全体に枠線と背景色が適用され、クイズ番組のような雰囲気を演出します。
- **画像**: 画面サイズに合わせて最大限大きく表示されます。
- **没入モード**: ヘッダーとフッターは非表示になります。

### 要素と動作の定義
| 要素名 | 種別 | 動作・仕様 |
| :--- | :--- | :--- |
| **正解を見る** | **ボタン** | クリックすると、この問題に対応する「解答表示ページ」に遷移する。 |

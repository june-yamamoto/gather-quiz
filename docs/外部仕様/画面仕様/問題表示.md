# 問題表示ページ

## 基本情報

- URL: `/gather/quizzes/:quizId`
- 目的: 選択した問題を会場全体へ投影する。
- レイアウト: ヘッダー・フッターなし。画面全体を使用する。

## 表示内容

- ジャンルがある場合は左上の色付きバッジ
- 右上に `{配点}点問題`
- 作成者名が取得できる場合は「作成者: {参加者名}」
- 問題文、問題画像、参考リンク
- 主催者が指定したラベル。選択問題では問題文の下に1始まりの番号付き選択肢を表示する。プレビューも同じ表示。
- 選択肢は丸い番号バッジ・淡い背景・枠・影を付けたカード。600px以上で2列、狭い画面では1列にする。カード自体は回答ボタンではない。
- 長い問題文・選択肢・動画・音声は本文領域内をスクロールする。画像と「正解を見る」は別領域に残し、横スクロールを発生させない。
- 「正解を見る」ボタン

文章の改行を維持し、問題文・解答文には「Q.」「A.」を付けず入力された本文を表示する。画像は表示領域内でアスペクト比を保って最大化する。参考リンクは新しいタブで開く。

## 動作

- 問題の取得API（GET/HEAD）は既読を変更しない。編集・先読み・プレビュー・解答画面への直接アクセスも既読にしない。
- 本番問題画面の描画後、問題画像があれば読み込み成功を待ち、タブが表示中の場合のみ `PUT /api/quizzes/:id/opened` でその問題を記録する。
- 表示前の画面離脱や画像取得失敗では既読にしない。同じ問題への再送は冪等で、他の問題には影響しない。
- 保存成功後にボードのキャッシュを無効化する。保存失敗は警告と「既読保存を再試行」を表示する。
- 「正解を見る」で同じ問題IDの解答表示ページへ遷移する。
- 読み込み中はスピナー、取得失敗時はインラインでエラーメッセージを表示する。

参加者ダッシュボードのプレビューは同じ表示コンポーネントを使うが、既読更新を行わず「正解を見る」も表示しない。

長文と画像は独立した領域に縦に並べる。本文だけをスクロールでき、画像は下部の固定領域で常に全体を表示する。問題・解答の画像はタップまたはキーボード操作で全画面に拡大でき、閉じるボタンまたはEscapeで元の表示に戻る。プレビューにも同じ表示を適用する。

## 動画・音声・URL

- 本文領域で動画・音声を操作付きプレイヤーとして表示する。自動再生せず、画面遷移・プレビュー終了時にはプレイヤーを破棄する。
- YouTube（watch・短縮URL・shorts・live・embed）はIFrame APIを用いて埋め込む。一般URLは新しいタブで開くリンク、拡張子付きの動画・音声URLは標準プレイヤーになる。未対応サービスはリンクとして利用できる。
- 画像は従来の領域で併用できる。狭い画面では本文・プレイヤー領域をスクロールし、画面遷移ボタンは残す。
- 404、コーデック非対応、YouTubeの非公開・埋め込み拒否、API遮断では警告・再試行・外部リンクを表示する。無応答やバッファ待ちも20秒で案内し、接続回復後に再試行できる。
- HTTP/HTTPS以外や不正な既存URLはリンクを生成せず、編集を促す。HTTPS画面でのHTTPメディアはブラウザに遮断される場合があるためHTTPSを推奨する。
- メディア付き問題は再生開始（画像併用時は画像ロードも完了）後に既読保存する。メタデータ取得・YouTubeプレイヤー準備だけでは既読にしない。プレビューは再生しても既読にしない。再生開始後の障害では既読を巻き戻さない。

選択肢コンテナは利用可能な横幅100%を使い、1100pxの固定上限を設けない。600px以上は2列、それ未満は1列。新規・更新時の選択肢は各100文字まで。既存の100文字超の選択肢は表示を保持し、再保存時に短縮を求める。

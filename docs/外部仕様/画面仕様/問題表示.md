# 問題表示ページ

## 基本情報

- URL: `/gather/quizzes/:quizId`
- 目的: 選択した問題を会場全体へ投影する。
- レイアウト: ヘッダー・フッターなし。画面全体を使用する。

## 表示内容

- ジャンルがある場合は左上の色付きバッジ
- 右上に `{配点}点問題`
- 作成者名が取得できる場合は「作成者: {参加者名}」
- 問題文、問題画像、参考リンク
- 「正解を見る」ボタン

文章の改行を維持し、画像は表示領域内でアスペクト比を保って最大化する。参考リンクは新しいタブで開く。

## 動作

- APIで問題を取得した時点で `isOpened` を `true` に更新する。
- 「正解を見る」で同じ問題IDの解答表示ページへ遷移する。
- 読み込み中はスピナー、取得失敗時はインラインでエラーメッセージを表示する。

参加者ダッシュボードのプレビューは同じ表示コンポーネントを使うが、既読更新を行わず「正解を見る」も表示しない。

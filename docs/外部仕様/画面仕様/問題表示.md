# 問題表示ページ

## 基本情報

- URL: `/gather/quizzes/:quizId`
- 目的: 選択した問題を会場全体へ投影する。
- レイアウト: ヘッダー・フッターなし。画面全体を使用する。

## 表示内容

- ジャンルがある場合は左上の色付きバッジ
- 右上に `{配点}点問題`
- 作成者名が取得できる場合は「作成者: {参加者名}」
- 問題文、問題画像、参考リンク
- 「正解を見る」ボタン

文章の改行を維持し、問題文・解答文には「Q.」「A.」を付けず入力された本文を表示する。画像は表示領域内でアスペクト比を保って最大化する。参考リンクは新しいタブで開く。

## 動作

- 問題の取得API（GET/HEAD）は既読を変更しない。編集・先読み・プレビュー・解答画面への直接アクセスも既読にしない。
- 本番問題画面の描画後、問題画像があれば読み込み成功を待ち、タブが表示中の場合のみ `PUT /api/quizzes/:id/opened` でその問題を記録する。
- 表示前の画面離脱や画像取得失敗では既読にしない。同じ問題への再送は冪等で、他の問題には影響しない。
- 保存成功後にボードのキャッシュを無効化する。保存失敗は警告と「既読保存を再試行」を表示する。
- 「正解を見る」で同じ問題IDの解答表示ページへ遷移する。
- 読み込み中はスピナー、取得失敗時はインラインでエラーメッセージを表示する。

参加者ダッシュボードのプレビューは同じ表示コンポーネントを使うが、既読更新を行わず「正解を見る」も表示しない。

長文と画像は独立した領域に縦に並べる。本文だけをスクロールでき、画像は下部の固定領域で常に全体を表示する。問題・解答の画像はタップまたはキーボード操作で全画面に拡大でき、閉じるボタンまたはEscapeで元の表示に戻る。プレビューにも同じ表示を適用する。

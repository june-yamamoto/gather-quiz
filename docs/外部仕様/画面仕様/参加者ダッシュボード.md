# 参加者ダッシュボードページ

## 基本情報

- URL: `/gather/tournaments/:tournamentId/participants/:participantId`
- 目的: 自分の問題作成状況を確認し、問題の作成・確認・編集を行う。
- レイアウト: 共通ヘッダー・フッターあり。

## 表示内容

- `{参加者名} さんのダッシュボード`
- 残りの作成問題数
- 大会の配点設定から生成した問題枠
- 作成済み問題のジャンル、問題文、解答文
- 問題・解答に画像またはリンクがあることを示すラベル
- 大会ポータルへ戻るボタン
- 大会にレギュレーションが設定されている場合のみ「ルール確認」

## 問題枠の操作

| 状態・操作 | 結果 |
| :--- | :--- |
| 未作成・作成する | 順序と配点をquery parameterに設定し、問題作成画面へ遷移する。 |
| 作成済み・問題確認 | 全画面ダイアログで問題をプレビューする。 |
| 作成済み・解答確認 | 全画面ダイアログで解答をプレビューする。 |
| 作成済み・編集 | 問題ID、順序、配点をquery parameterに設定し、編集画面へ遷移する。 |

プレビュー取得には `preview=true` を付けるため、問題を既読に更新しない。プレビュー内には本番画面の遷移ボタンを表示せず、右上の閉じるボタンで戻る。

## 状態・エラー

- 読み込み中はスピナーを表示する。
- 作成状況の取得に失敗した場合はインラインでエラーメッセージを表示する。
- 参加者IDに対する認証・所有者確認はない。
- 大会開始後も作成・編集ボタンを無効化しない。

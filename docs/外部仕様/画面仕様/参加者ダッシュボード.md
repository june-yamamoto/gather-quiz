## 12. 参加者ダッシュボードページ

### 画面の目的
- 参加者が自分の問題作成状況を把握し、各問題の作成・編集作業を行うためのハブ画面。

### 画面レイアウト

```
+----------------------------------------------------------------------+
| ヘッダー                                                             |
|   GatherQuiz                                                         |
+----------------------------------------------------------------------+
| メインコンテンツ                                                       |
|   ## Tanaka さんのダッシュボード                                      |
|                                                                      |
|   問題作成ステータス                                                   |
|   あと [ 2 ] 問、作成してください。                                    |
|                                                                      |
|   問題リスト                                                           |
|   +--------------------------------------------------------------+   |
|   | 第1問 (10点)                                                 |   |
|   | Q. 日本で一番高い山は？                                      |   |
|   | A. 富士山                                                    |   |
|   |                                           [ 編集する ]       |   |
|   +--------------------------------------------------------------+   |
|   | 第2問 (20点)                                                 |   |
|   | (未作成)                                                     |   |
|   |                                           [ 作成する ]       |   |
|   +--------------------------------------------------------------+   |
|   | ...                                                          |   |
|   +--------------------------------------------------------------+   |
+----------------------------------------------------------------------+
```

### 各要素の説明
- **参加者名**: ログイン中のユーザー名を表示。
- **ステータス**: 残りの作成必要数を表示し、タスクの完了を促す。
- **問題リスト**: 大会の配点設定に基づき、必要な問題スロットを一覧表示する。

### 要素と動作の定義
| 要素名 | 種別 | 動作・仕様 |
| :--- | :--- | :--- |
| **作成する** | **ボタン** | ・未作成のスロットに表示。<br>・クリックすると、その配点・順序で「問題作成・編集ページ」へ遷移する。 |
| **編集する** | **ボタン** | ・作成済みのスロットに表示。<br>・クリックすると、その問題を編集モードで「問題作成・編集ページ」へ遷移する。 |

### 設計のポイント
- **タスクの明確化**: 何をどれだけ作れば良いか、次にどのアクション（作成/編集）を取れば良いかを明確にする。

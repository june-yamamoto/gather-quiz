# 大会作成・編集ページ

## 基本情報

- 新規作成URL: `/gather/tournaments/new`
- 編集URL: `/gather/tournaments/:tournamentId/edit`
- 目的: 大会名、問題数、配点、ルール、ジャンル、管理用パスワードを登録・更新する。
- レイアウト: 共通ヘッダー・フッターあり。

## 入力項目

| 項目 | 新規作成 | 編集 | 現行の入力制約 |
| :--- | :--- | :--- | :--- |
| 大会名 | 必須 | 必須・既存値表示 | HTMLの必須入力。 |
| 管理用パスワード | 必須 | 変更時のみ | パスワード入力。長さ・文字種・確認欄の検証はない。 |
| 参加者1人あたりの問題作成数 | 必須・初期値3 | 必須・既存値表示 | 数値、1～10。 |
| 各問題の配点 | 必須・初期値10/20/30 | 必須・既存値表示 | 問題数に応じて欄を増減。1〜2147483647の整数。 |
| 各問題のラベル | 任意 | 既存値表示 | 50文字以内。例: 声優、音楽。同じ配点でも問題順で区別する。 |
| 各問題の出題形式 | 必須・初期値通常問題 | 既存値表示 | 通常問題／選択問題。択数は参加者が決める。 |
| レギュレーション | 任意 | 任意・既存値表示 | 4行のテキスト入力。文字数制限はない。 |
| ジャンル設定 | 任意 | 任意・既存値表示 | カンマ区切り。問題作成時の選択肢に使う。 |

大会IDはバックエンドがUUIDで自動発行する。大会キービジュアル、パスワード確認欄は現行画面に存在しない。

## 操作と結果

- 新規作成で送信に成功すると大会作成完了ページへ遷移し、入力したパスワードを画面間stateで渡す。
- 編集画面は大会情報を取得してフォームへ反映する。更新成功時はアラートを表示し、主催者用管理画面へ戻る。
- 作成・更新に失敗した場合はアラートを表示し、その画面に留まる。

## 現行実装上の制約

- 新規作成・編集ともにジャンルと問題枠設定を保存する。ラベルは主催者が割り当てる分類であり、参加者が選ぶジャンルとは別項目。
- 作成済みの問題が1件でもある大会では、問題数・配点・ラベル・出題形式の変更をAPIで拒否する。大会名・ルール等は更新可能。参加者は選択問題の択数を変更できる。
- 旧大会はラベルなし・通常問題として表示する。同じ問題順の設定は問題数増減時に保持し、削除された末尾枠の設定は破棄する。
- 「開始後は編集不可」という案内が管理画面にあるが、この画面とAPIには開始状態による更新拒否がない。

## 主催者による出題形式・参加者による択数の設定

大会作成では問題枠のラベル・配点・通常問題／選択問題を設定する。選択肢数は指定せず、選択問題を割り当てられた参加者が問題作成・編集時に2〜20択から設定する。JSONのquestionTypeにnormal/choiceを保存し、APIでも形式を強制する。旧大会のquestionType未設定枠は互換性のため従来動作を保持する。

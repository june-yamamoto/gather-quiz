## 9. 解答表示ページ

### 画面の目的
- 問題の正解（解答文、画像、リンク）を分かりやすく表示し、スムーズに問題選択ボードへ戻れるようにする。

### 画面レイアウト

```
+----------------------------------------------------------------------+
|  Q. ここに問題文が（ヘッダーとして）表示されます。                   |
| -------------------------------------------------------------------- |
|                                                                      |
|      A. ここに解答文が大きな文字で表示されます。                     |
|                                                                      |
|               +----------------------------------+                   |
|               | (ここに解答の添付画像が大きく表示) |                   |
|               +----------------------------------+                   |
|      解答の参考リンク： https://example.com/answer                   |
|                                                                      |
|                   +----------------------------------+               |
|                   |        [ ボードに戻る ]        |               |
|                   +----------------------------------+               |
+----------------------------------------------------------------------+
```

### デザインの特徴
- **装飾**: 問題表示ページとは異なるテーマカラー（赤系など）で枠線と背景色が適用され、解答画面であることを強調します。
- **画像**: 画面サイズに合わせて最大限大きく表示されます。
- **没入モード**: ヘッダーとフッターは非表示になります。

### 要素と動作の定義
| 要素名 | 種別 | 動作・仕様 |
| :--- | :--- | :--- |
| **ボードに戻る** | **ボタン** | クリックすると、「問題選択ボードページ」に戻る。 |

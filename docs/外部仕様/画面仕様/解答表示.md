# 解答表示ページ

## 基本情報

- URL: `/gather/quizzes/:quizId/answer`
- 目的: 選択した問題の解答を投影し、問題選択ボードへ戻す。
- レイアウト: ヘッダー・フッターなし。画面全体を使用する。

## 表示内容

- 上部に問題文
- 赤系の枠と解答文（`A.` 接頭辞は付けない）
- 正解が設定された選択問題では、全選択肢を表示し、正解を枠・背景色・「✓ 正解」の表示で強調する。解答文やメディアも併記する。未設定の旧問題では全選択肢を同じ見た目で表示する。
- 解答画像と参考リンク
- 「ボードに戻る」ボタン

文章の改行を維持し、画像は表示領域内でアスペクト比を保って最大化する。参考リンクは新しいタブで開く。

## 動作

- 問題データを取得する。解答画面への直接アクセスや取得によって既読にはならない。
- 「ボードに戻る」で問題データの大会IDを使い、問題選択ボードへ遷移する。
- 読み込み中はスピナー、取得失敗時はインラインでエラーメッセージを表示する。

参加者ダッシュボードのプレビューは同じ表示コンポーネントを使うが、既読更新を行わず「ボードに戻る」も表示しない。

## 動画・音声・URL

- 本文領域で動画・音声を操作付きプレイヤーとして表示する。自動再生せず、画面遷移・プレビュー終了時にはプレイヤーを破棄する。
- YouTube（watch・短縮URL・shorts・live・embed）はIFrame APIを用いて埋め込む。一般URLは新しいタブで開くリンク、拡張子付きの動画・音声URLは標準プレイヤーになる。未対応サービスはリンクとして利用できる。
- 画像は従来の領域で併用できる。狭い画面では本文・プレイヤー領域をスクロールし、画面遷移ボタンは残す。
- 404、コーデック非対応、YouTubeの非公開・埋め込み拒否、API遮断では警告・再試行・外部リンクを表示する。無応答やバッファ待ちも20秒で案内し、接続回復後に再試行できる。
- HTTP/HTTPS以外や不正な既存URLはリンクを生成せず、編集を促す。HTTPS画面でのHTTPメディアはブラウザに遮断される場合があるためHTTPSを推奨する。

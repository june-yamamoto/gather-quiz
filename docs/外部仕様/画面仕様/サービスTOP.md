# サービスTOPページ

## 基本情報

- URL: `/gather`
- 目的: 新しい大会の作成と、過去に閲覧した大会への再アクセスを提供する。
- レイアウト: 共通ヘッダー・フッターあり。

## 表示内容

- サービス名 `GatherQuiz`
- 「みんなで問題を持ち寄る、クイズ大会開催ツール」という説明
- 「クイズ大会を新しく作成する」ボタン
- 閲覧履歴がある場合のみ「最近アクセスした大会」一覧

## 操作

| 操作 | 結果 |
| :--- | :--- |
| クイズ大会を新しく作成する | 大会作成ページへ遷移する。 |
| 最近アクセスした大会を選ぶ | 選択した大会のポータルへ遷移する。 |

## 閲覧履歴

- 大会ポータルの取得成功時に、`localStorage` の `viewedTournaments` へ大会ID、名称、閲覧時刻を保存する。
- 同じ大会は最新の1件にまとめ、直近5大会まで表示する。
- 履歴が空の場合、一覧セクション自体を表示しない。

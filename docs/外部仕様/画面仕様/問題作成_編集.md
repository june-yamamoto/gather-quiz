# 問題作成・編集ページ

## ラベルと選択問題

- 大会設定を取得後、問題順に対応するラベル・配点を表示する。ラベル・配点は参加者が変更できない。出題形式は主催者が指定する。選択問題の場合のみ参加者が2〜20択の選択肢数を設定する。取得失敗時は保存を禁止する。
- 選択問題には参加者が指定した2〜20個の選択肢入力欄を表示する。全欄必須、各1〜100文字（前後の空白除去後）。
- 各選択肢の横で正解を1つ指定できる。解答文も自由に入力でき、正解を指定した場合は解答文の省略も可能。択数を減らして正解の選択肢が消えた場合は指定を解除する。自動採点は行わない。
- 選択肢は順序を保って保存・再取得・再編集できる。通常問題には選択肢欄を表示しない。
- APIは大会の問題枠からラベル・出題形式を決定し、選択肢数・配点・参加者の所属大会を検証する。
- 参加者ダッシュボードと問題ボードにも問題枠のラベルと作成済み問題の選択肢数を表示する。

## 基本情報

- URL: `/gather/tournaments/:tournamentId/participants/:participantId/quizzes/new`
- 新規作成query: `?order={0始まりの順序}&point={配点}`
- 編集query: `?edit={quizId}&order={順序}&point={配点}`
- 目的: 指定された問題枠の問題と解答を作成・編集する。
- レイアウト: URLに `/quizzes/` を含むため、現行の共通レイアウト判定ではヘッダー・フッターを表示しない。

## 入力項目

| 項目 | 仕様 |
| :--- | :--- |
| 配点 | query parameterまたは既存問題から表示する読み取り専用の数値。 |
| ジャンル | 大会にジャンルがある場合のみ表示し、未選択または1件を選べる。 |
| 問題文・解答文 | 任意の複数行テキスト。 |
| 問題画像・解答画像 | JPEG・PNG・GIF・WebP・AVIF、1バイト以上10 MB以下。選択ファイル名または既存画像ありを表示し、削除できる。 |
| 問題参考リンク・解答参考リンク | 動画・音声ファイルまたはHTTP/HTTPS URLを1件設定。ファイル選択取消・削除・置換に対応。認証情報入りや2048文字超のURLは不可。 |

問題側・解答側それぞれ、文章・画像・動画・音声・URLのいずれかが必須。ただし選択問題で正解を指定した場合、解答側の文章・添付は任意。空白だけの文章は内容として扱わない。動画はMP4・WebM、音声はMP3・M4A・WAV・Ogg・WebM、1バイト以上100 MB以下。再生可否はブラウザのコーデック対応にも依存する。

## 操作と結果

- 大会情報の取得後、「大会ルールを確認」でレギュレーションをダイアログ表示する。
- 編集時の問題取得・保存で既読は変更しない。
- 新しい画像を選んだ場合、S3署名付きURLを取得してアップロード後、問題を保存する。
- 作成・更新成功時はアラートを表示し、参加者ダッシュボードへ戻る。
- 転送・保存失敗は理由をインライン表示し、入力を保持して再試行できる。転送済みファイルは保存再試行時に再利用する。保存中はフォームを無効化して多重送信を防ぐ。

## 現行実装上の制約

スマートフォンでは問題・解答を縦に配置し、16px以上の入力文字と44px以上の操作領域を使う。参考リンクはURL用キーボードを指定し、保存ボタンは画面下端に追従する。

- 既存画像の作成画面内プレビューはない。画像は削除・置換できる。動画・音声の選択取消は既存URLを保持し、削除はファイル選択とURLを消す。
- 参加者本人か、大会が開始済みかを検証するアクセス制御はない。
- 編集リクエストでは `order` を送るが、バックエンドは順序を更新しない。

## 保存と運用

- 正解選択肢は `Quiz.correctChoiceIndex` に0始まりの番号またはnullとして保持する。`0004_correct_choice` で既存行を保持したままnullable列を追加する。未設定の既存問題は解答文から推測して補完しない。

- 既存の questionLink / answerLink に添付メディアURLを保存し、画像とは独立して併用する。1側につき画像1件とメディア/URL1件。DBスキーマ・バックアップ形式の変更やマイグレーションは不要。
- 動画・音声は `/api/upload/media` で署名を発行し、既存の非公開S3の uploads 配下へブラウザから直接PUTする。署名にはMIMEとバイト数を含め、拡張子はサーバーがMIMEから決定する。実体のコーデック変換や内容解析は行わない。
- 署名取得の待機上限30秒、転送5分。保存前の転送後に画面を離脱すると未参照オブジェクトが残り得る。添付削除は問題からの参照削除であり、S3実体は削除しない。
- YouTubeと拡張子付き直接メディアURLは問題・解答・プレビューで再生する。その他URLは通常リンク。外部サービスの公開状態・埋め込み許可やネットワーク接続が必要。

questionType未設定の旧大会は既存問題の形式・選択肢を保持し、従来の形式切替を許可する。新規大会の通常問題／選択問題は参加者が変更できない。既存JSONの拡張のみで、DBスキーマ移行は不要。

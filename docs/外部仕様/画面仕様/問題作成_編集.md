# 問題作成・編集ページ

## 基本情報

- URL: `/gather/tournaments/:tournamentId/participants/:participantId/quizzes/new`
- 新規作成query: `?order={0始まりの順序}&point={配点}`
- 編集query: `?edit={quizId}&order={順序}&point={配点}`
- 目的: 指定された問題枠の問題と解答を作成・編集する。
- レイアウト: URLに `/quizzes/` を含むため、現行の共通レイアウト判定ではヘッダー・フッターを表示しない。

## 入力項目

| 項目 | 仕様 |
| :--- | :--- |
| 配点 | query parameterまたは既存問題から表示する読み取り専用の数値。 |
| ジャンル | 大会にジャンルがある場合のみ表示し、未選択または1件を選べる。 |
| 問題文・解答文 | 任意の複数行テキスト。 |
| 問題画像・解答画像 | `accept="image/*"` のファイル選択。選択ファイル名または既存画像ありを表示する。 |
| 問題参考リンク・解答参考リンク | 任意テキスト。URL形式の検証はない。 |

問題側は文章か画像の少なくとも一方、解答側も文章か画像の少なくとも一方を必須とする。画像のサイズや内容のクライアント検証はない。

## 操作と結果

- 大会情報の取得後、「大会ルールを確認」でレギュレーションをダイアログ表示する。
- 編集時は問題を通常取得するため、その取得によって未読問題も既読になる。
- 新しい画像を選んだ場合、S3署名付きURLを取得してアップロード後、問題を保存する。
- 作成・更新成功時はアラートを表示し、参加者ダッシュボードへ戻る。
- 失敗時は「エラーが発生しました。」とアラート表示し、画面に留まる。

## 現行実装上の制約

- 既存画像のプレビュー、削除、選択取消はない。新しい画像を選ぶと既存URLを置き換える。
- 参加者本人か、大会が開始済みかを検証するアクセス制御はない。
- 編集リクエストでは `order` を送るが、バックエンドは順序を更新しない。

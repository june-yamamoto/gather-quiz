## 6. 問題作成・編集ページ

### 画面の目的
- 参加者が、割り当てられた配点に応じたクイズ（問題と解答）を作成・編集する。

### 画面レイアウト

```
+----------------------------------------------------------------------+
| ヘッダー                                                             |
|   GatherQuiz                                                         |
+----------------------------------------------------------------------+
| メインコンテンツ                                                       |
|   ## 問題の作成（または編集）                 [ 大会ルールを確認 ]     |
|                                                                      |
|   配点: [ 10 ] (変更不可)    ジャンル: [ (選択なし) v ]              |
|                                                                      |
|   +----------------------------+  +--------------------------------+ |
|   |  ### 問題の作成            |  |  ### 解答の作成                | |
|   |                            |  |                                | |
|   |  問題文:                   |  |  解答文:                       | |
|   |  [ ____________________ ]  |  |  [ ____________________ ]      | |
|   |                            |  |                                | |
|   |  [ 添付画像を選択 ]        |  |  [ 添付画像を選択 ]            | |
|   |  (selected_file.jpg)       |  |                                | |
|   |                            |  |                                | |
|   |  参考リンク:               |  |  参考リンク:                   | |
|   |  [ ____________________ ]  |  |  [ ____________________ ]      | |
|   +----------------------------+  +--------------------------------+ |
|                                                                      |
|                  +----------------------------------+                |
|                  |   [ この内容で問題を保存する ]   |                |
|                  +----------------------------------+                |
+----------------------------------------------------------------------+
```

### 各要素の説明
- **配点**: ダッシュボードで選択した問題の配点が表示されます（編集不可）。
- **問題・解答入力エリア**: 左右（または上下）に対比させる形で配置。
- **保存ボタン**: 入力内容を保存し、ダッシュボードへ戻ります。

### 要素と動作の定義
| 要素名 | 種別 | 動作・仕様 |
| :--- | :--- | :--- |
| 配点 | テキスト（Read-only） | URLパラメータから取得した配点を表示。ユーザーは変更できない。 |
| ジャンル | セレクトボックス | ・大会でジャンルが設定されている場合のみ表示される<br>・設定されたジャンルから1つ選択できる（任意） |
| 大会ルールを確認 | ボタン | ・クリックすると、大会のレギュレーションを表示するダイアログが開く |
| 問題文 / 解答文 | テキストエリア | クイズのテキスト情報。 |
| 添付画像 | ファイル入力 | 画像をアップロードする。既存の画像がある場合はファイル名やプレビューを表示。 |
| **この内容で問題を保存する** | **ボタン** | ・バリデーション（問題/解答のどちらかは必須など）を実行。<br>・成功すればデータを保存し、「参加者ダッシュボードページ」へ遷移する。 |

### 設計のポイント
- **文脈の維持**: どの配点の問題を作っているかを明示し、ユーザーの迷いを防ぐ。
- **効率的な入力**: 問題と解答を1画面で入力できるようにし、思考の流れを止めない。

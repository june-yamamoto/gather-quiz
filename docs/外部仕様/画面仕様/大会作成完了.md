# 大会作成完了ページ

## 基本情報

- URL: `/gather/tournaments/:id/created`
- 目的: 大会作成の完了を伝え、招待URLと管理用パスワードを案内する。
- レイアウト: 共通ヘッダー・フッターあり。

## 表示内容

- 完了メッセージと、URLを保管するよう促す注意文
- APIから大会情報を取得できた場合、大会名、招待URL、管理用パスワードをカード表示
- 招待URLは `window.location.origin` と大会ポータルのパスから生成する。
- 管理用パスワードは大会作成画面から渡された画面間stateを表示する。ページの再読込やURLへの直接アクセスでstateがない場合は `********` と表示する。

## 操作

| 操作 | 結果 |
| :--- | :--- |
| コピー | Clipboard APIで招待URLをコピーし、成功・失敗をアラート表示する。 |
| 大会ポータルへ移動 | 作成した大会のポータルへ遷移する。 |

管理用パスワードをAPIから再取得して表示する処理はない。

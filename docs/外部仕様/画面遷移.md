# 画面遷移

最終実装確認日: 2026-08-30

## 主催者

1. サービスTOPで「クイズ大会を新しく作成する」を押す。
2. 大会作成画面で必須項目を入力し、「この内容で大会を作成する」を押す。
3. 大会作成完了画面で招待URLと管理用パスワードを確認する。
4. 「大会ポータルへ移動」から大会ポータルへ進む。
5. 「主催者としてログイン」で管理用パスワードを入力する。
6. 主催者用管理画面で参加者ごとの作成数を確認する。
7. 必要に応じて「大会概要を編集する」から大会編集画面へ進み、更新後に管理画面へ戻る。
8. 「この内容で大会を開始する」を押すと、確認ダイアログなしで大会が開始状態になり、問題選択ボードへ進む。
9. 開始済みの場合は「問題ボードへ移動する」からボードへ進む。

## 参加者

### 初回登録

1. 招待URLから大会ポータルへアクセスする。
2. 「参加者として新規登録」を押す。
3. 名前を入力し、「この名前で参加する」を押す。
4. 同じ画面に表示された自動生成パスワードを控える。
5. 「ダッシュボードへ移動する」を押す。

### 再ログイン

1. 大会ポータルで「参加者としてログイン」を押す。
2. 名前と発行済みパスワードを入力する。
3. 認証成功後、参加者ダッシュボードへ進む。

### 問題作成・編集

1. 参加者ダッシュボードの未作成枠で「作成する」を押す。
2. 問題と解答を入力し、保存するとダッシュボードへ戻る。
3. 作成済み枠では「問題確認」「解答確認」で既読を付けずに全画面プレビューできる。
4. 「編集」から問題作成・編集画面へ進み、更新するとダッシュボードへ戻る。

## 大会進行

1. 問題選択ボードで作成済みの問題カードを選ぶ。
2. 問題表示画面を取得した時点で、その問題が既読になる。
3. 「正解を見る」で解答表示画面へ進む。
4. 「ボードに戻る」で問題選択ボードへ戻る。
5. 作成済み問題が1問以上あり、その全てが既読になると「大会を終了する！」が表示される。
6. ボタンを押すと大会終了ダイアログが開き、「大会ポータルへ戻る」でポータルへ進む。

未作成枠は終了判定に含めない。大会終了操作は現行実装では大会ステータスを `finished` に更新しない。

## エラー

- 未定義URLはエラーページを表示する。
- API取得エラーは、画面によってインラインのエラー文またはブラウザのアラートで表示する。
- ログイン失敗は大会ポータル上のアラートで通知し、専用エラーページへは遷移しない。

# 外部仕様：ステップ2 画面遷移図

## 👑 主催者の操作フロー

### 大会作成
1. **サービスTOPページ**にアクセスする
2. `[新しい大会を作成する]` ボタンを押す
   → **大会作成ページ**に移動
3. 必要事項をすべて入力し、`[作成する]` ボタンを押す
   → **大会作成完了ページ**に移動 (ここで招待URLと管理パスワードを控える)

### 大会の管理・編集 (大会開始前)
1. 作成した大会の招待URLにアクセスする
   → **大会ポータルページ**に移動
2. 「主催者入口」で管理パスワードを入力してログインする
   → **主催者用 管理ページ**に移動
3. 管理ページでは以下のことが可能:
   - **参加者の問題作成状況を確認する** (一覧表示)
   - **大会概要を編集する**
     - `[大会概要を編集する]` ボタンを押すと、**大会作成ページ**（編集モード）に移動し、内容を修正できる。修正後は**主催者用 管理ページ**に戻る。
   - **大会を開始する**
     - 参加者の準備が完了していることを確認し、`[大会を開始する]` ボタンを押す。

## ✍️ 参加者の操作フロー

### 初回登録
1. 主催者から共有された招待URLにアクセスする
   → **大会ポータルページ**に移動
2. `[参加者として新規登録]` ボタンを押す
   → **参加者登録ページ**に移動
3. 名前を入力して登録する
   → **登録完了画面**が表示される（ここで自動生成されたパスワードを控える）
4. `[ダッシュボードへ移動する]` ボタンを押す
   → **参加者ダッシュボードページ**に移動

### 2回目以降（ログイン）
1. 招待URLにアクセスする
   → **大会ポータルページ**に移動
2. `[参加者としてログイン]` ボタンを押す
   → ログインダイアログが表示される
3. 名前とパスワードを入力してログインする
   → **参加者ダッシュボードページ**に移動

### 問題作成
1. **参加者ダッシュボードページ**にて、作成したい問題（例: 第1問 10点）の `[作成する]` ボタンを押す
   → **問題作成・編集ページ**に移動
2. 問題と解答を入力し、保存する
   → **参加者ダッシュボードページ**に戻る
3. 全ての問題を作成したら、ブラウザを閉じて終了する。

## 🎬 大会当日のフロー
1. 主催者が**主催者用 管理ページ**から `[大会を開始する]` ボタンを押す
   （または「ボードへ移動する」ボタンを押す）
   → **問題選択ボードページ**に移動 (プロジェクターに投影開始)
2. ボード上の問題を選択する
   → **問題表示ページ**に移動
3. `[正解を見る]` ボタンを押す
   → **解答表示ページ**に移動
4. `[ボードに戻る]` ボタンを押す
   → **問題選択ボードページ**に移動 (選択した問題は「出題済み（グレーアウト）」になる)
5. (上記 2〜4 を繰り返し、全ての問題が出題される)
   → **大会終了ページ**が表示される

## ⚠️ 共通のエラーフロー
- 存在しない招待URLにアクセスした場合 → **エラーページ**に移動
- ログインに失敗した場合 → エラーメッセージを表示
